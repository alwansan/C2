# تشغيل إضافة سينمانا

## على الهاتف نفسه

Termux الرسمي: https://github.com/termux/termux-app/releases

```sh
pkg install git nodejs-lts
git clone https://github.com/alwansan/C2.git
cd C2
bash tools/start-termux.sh
```

افتح `http://127.0.0.1:7000/configure`. اضغط اختبار الاتصال أولًا. إذا نجح، تختار إعداد الترجمة المناسب ثم تنسخ الرابط إلى صفحة الإضافات في Nuvio أو تستخدم زر فتح Stremio. رابط الهاتف المحلي يعمل على الجهاز الذي يشغل الخدمة فقط. إذا رفض إصدار العميل HTTP المحلي، تحتاج رابط HTTPS لخدمة قابلة للوصول.

يمكن تنفيذ `termux-wake-lock` إذا كان Android يوقف الخدمة أثناء المشاهدة؛ تذكر أن إبقاء Termux يعمل شرط استمرار المزود. التحديث: أوقف الخدمة ثم `git pull --ff-only` وأعد تشغيلها.

## الإعدادات

انسخ `.env.example` إلى `.env` وعدل ما تحتاجه. Node يقرأ الملف تلقائيًا عند `npm start` وباقي أدوات المشروع. لا توجد كلمات مرور أو رموز وصول ضمن المستودع.

| المتغير | الاستخدام |
|---|---|
| `HOST` | افتراضيًا الهاتف نفسه `127.0.0.1`؛ استخدم `0.0.0.0` عند توفير خدمة لأجهزة أخرى |
| `PORT` | 7000 افتراضيًا |
| `PUBLIC_URL` | عنوان الخدمة كما يصل إليه العميل، بلا `/manifest.json` أو `/c/...` أو استعلام |
| `DATA_DIR` | حفظ الفهرس والتشخيص والسجلات |
| `CINEMANA_API_BASE` | عنوان API الأصلي؛ يغير فقط إذا ثبت تغيره |
| `CINEMANA_AUTHORIZATION` | قيمة التفويض الأصلية المشروعة كما هي، اختيارية؛ دون إضافة تلقائية لـ Bearer |
| `CINEMANA_USER_AGENT` | نمط User-Agent الأصلي، قابل للتحديث |
| `CINEMANA_MEDIA_HEADERS` | JSON لرؤوس الفيديو إذا احتاجها المصدر؛ منفصلة عن رؤوس API |
| `REQUEST_TIMEOUT_MS` | مهلة الطلب الواحد للمزود؛ افتراضيًا 12000 |
| `PAGES_PER_REQUEST` | افتراضيًا 40 صفحة أصلية؛ تجاوزه يعيد خطأ قابل للاستكمال بدل بحث ناقص |
| `CATALOG_TTL_MS` | ذاكرة الفهرس والمؤشرات، افتراضيًا 15 دقيقة |
| `ADDON_ACCESS_KEY` | مفتاح تثبيت خاص من 24–128 حرفًا؛ يصبح المسار `/k/<key>/manifest.json` |

إذا استعملت تفويض حساب على خدمة متاحة لآخرين، اضبط مفتاح تثبيت خاص. يمكن توليده محليًا: `node -e "console.log(require('node:crypto').randomBytes(24).toString('base64url'))"`.

للحفظ في المسار الذي طلبه علوان، شغل `termux-setup-storage` وامنح Termux إذن التخزين، ثم:

```dotenv
DATA_DIR=/storage/emulated/0/AlwanCinema/work/data
```

هذه بيانات خدمة الإضافة فقط. لا تُنشأ مجلدات APK القديمة، ولا تُنقل تنزيلاته؛ التنزيل واستعادة مكتبة المستخدم يتبعان العميل. احفظ مجلد الخدمة أو نسخة احتياطية قبل حذف Termux إذا كان `DATA_DIR` داخل تخزينه الخاص.

## خدمة LAN أو HTTPS

العنوان الصحيح يشير إلى **خادم يستطيع بنفسه الوصول إلى API سينمانا**. نجاح الوصول من هاتفك لا يثبت نجاح الوصول من مركز بيانات بعيد. ضع `PUBLIC_URL` على العنوان الذي سيستعمله العميل؛ لا تستخدم `127.0.0.1` لجهاز آخر.

المشروع يشمل Docker وCompose:

```sh
cp .env.example .env
docker compose up --build -d
```

Compose يحفظ `data` في volume دائم ويربط المنفذ محليًا فقط. للاستضافة العامة، استعمل reverse proxy على الجهاز نفسه مع HTTPS ومرره إلى `127.0.0.1:7000`، واضبط `PUBLIC_URL=https://your-domain.example` إلى نطاقك الفعلي. إبقاء `HOST=0.0.0.0` داخل الحاوية ضروري؛ Compose يضبطه تلقائيًا.

GitHub يحتفظ بالمصدر، وActions ينفذ الاختبارات والتشخيص. GitHub Pages لا يشغل خادم Node، ولا يوفر كتالوجات ديناميكية من ملف ثابت. لم يُنشأ أو يُشترَ نطاق أو خادم سحابي في هذه المهمة.

## فحص الاتصال

```sh
npm test
npm run inspect
npm run manifest -- --output=manifest-live.json
npm run capture -- 12345 67890
```

الأرقام أمثلة يجب استبدالها. `inspect` يحتاج نجاح قوائم الأقسام وفروع التجميعات؛ لا يعتبر نجاح HTTP واحد دليلًا على اكتمال الفهرس. `capture` يحفظ التصنيفات والرئيسية والتجميعات وتفاصيل الأرقام والجودات والحلقات؛ هذه البيانات قد تحتوي روابط مؤقتة، وتظل خارج Git.

مسارات التشخيص بعد التشغيل:

- `/health.json`: هل الخدمة تعمل، مع آخر حالة اكتشاف.
- `/diagnostics.json`: الحالة والإعدادات دون الرموز أو روابط الفيديو الكاملة.
- `/native/index.json`: الفهرس الخام الذي اكتشفته الخدمة.
- `/native/details/alwan.cinemana:12345.json`: تفاصيل أصلية، ونظائر `episodes/transcodes/comments/staff`.

عند استخدام مفتاح تثبيت أو إعداد `/c/...`، أضف بادئته إلى المسارات عدا health.

## الطلبات والفلترة

كل مسار catalog يستخدم `type` ثم معرف كتالوج من manifest. الإضافات بعد المعرف بصيغة URL القياسية:

```text
/catalog/movie/cinemana-search-movie/search=demon.json
/catalog/series/cinemana-all-series/skip=100.json
/catalog/movie/cinemana-all-movie/year=2020,2024&rating=7.json
```

في كتالوج التصنيف الثابت، `genre` يختار لغته، مثل `genre=العربية [lang:12]` بعد ترميز URL. في الكتالوج العام والبحث، `genre` يختار التصنيف. `language` يبقى للغة في كل هذه المسارات. تُؤخذ المعرفات من manifest نفسه؛ لا تختلق معرفًا. `sort` يأخذ أحد خيارات manifest، ويُرسل بالقيمة الأصلية. فرز AdvancedSearch غير موجود في العقد، ولذلك يرفض الجمع بين البحث وsort بدل تجاهل المستخدم. لا تدعم المجموعات المنسقة فلترة أصلية؛ تعرض ترتيبها الأصلي. بعض العملاء يعرضون genre فقط ويتجاهلون خيارات إضافية؛ لهذا استُخدم genre لاختيار اللغة داخل كتالوج التصنيف الموحد.

## تفسير الأخطاء

| الرمز | المعنى |
|---|---|
| `UPSTREAM_NETWORK` | شبكة الخدمة لا تصل إلى المزود أو تجاوزت المهلة |
| `UPSTREAM_ACCESS` | رفض المزود الوصول 401/403؛ تحقق من الشبكة وصلاحياتك |
| `UPSTREAM_JSON / UPSTREAM_SHAPE` | الرد مختلف عن العقد الذي حللناه |
| `PAGE_BUDGET` | لم تكتمل صفحات الطلب؛ كرر الطلب نفسه للاستكمال أو ارفع الميزانية بما يناسب المهلة |
| `REPEATED_PAGE` | أعاد المزود صفحة سابقة؛ لا يُعلن نهاية وهمية |
| `IDENTITY` | المعرف أو نوع العمل أو هوية التفاصيل لا تتطابق |
| `FILTER` | خيار غير معروف أو تركيب لا يدعمه المصدر |

الأخطاء غير مخزنة ككتالوج فارغ ناجح. إذا فشل أول اكتشاف، يفشل manifest بوضوح. إذا سبق اكتشاف كامل ثم تعطلت الشبكة، يحتفظ بالأقسام القديمة مع حالة `disk-stale`.
