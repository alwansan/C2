# تقرير التحقق — 2026-10-11

## النتيجة المحلية

`npm test`: **40 حالة اختبار، 40 ناجحة، 0 فشل** على Node.js 24.19.0.

- موارد manifest/catalog/meta/stream/subtitles تعمل عبر HTTP محلي حقيقي، مع CORS وصفحة الإعداد والشعار والمسارات المكوّنة والمفتاح الخاص.
- اكتشاف أقسام/لغات/مجموعات/تجميعات وفروع مصطنعة؛ رفض إعلان فهرس مكتمل عند فشل جزء من الاكتشاف، والحفاظ على فهرس سابق بحالة قديمة معلنة.
- ترقيم المصدر يبدأ من صفر؛ صفحات قصيرة ومختلطة ومتكررة، إزالة تكرار، offsets بعد الفلترة، طلبات متزامنة ورجوع لصفحات سابقة.
- بحث بأكثر من 100 نتيجة: جمع 260 نتيجة من صفحات مصطنعة دون الاقتصار على الاستجابة الأولى القصيرة.
- الفلترة بالسنة وIMDb تستمر بعد صفحة لا تنتج نتائج؛ التركيبات غير المدعومة تُرفض بدل تجاهلها.
- هوية الفيديو والحلقة والأصل دقيقة؛ يرفض ردًا برقم آخر، ويحتفظ بالمواسم الخاصة والحقول الأصلية.
- كل نسخ الترجمة تبقى متاحة؛ تمييز المحسنة، صيغ ASS واللغات غير المعروفة، أسماء مشتركة وروابط موقعة.
- كل الجودات باقية مع ترتيب الجودة المفضلة؛ لا تنتقل رموز API تلقائيًا إلى طلب الفيديو أو سجلات الخطأ.

مصدر بيانات هذه الاختبارات **JSON مصطنع وmock HTTP محلي**. لا توجد تشغيلات على هاتف فعلي داخل هذه البيئة، ولا مقارنة حية لكل نتائج كلمة بحث من تطبيق سينمانا.

## الاتصال الحي من بيئة البناء

`REQUEST_TIMEOUT_MS=2000 npm run inspect` أعاد فشل `UPSTREAM_NETWORK` للتصنيفات ومجموعات الرئيسية والتجميعات. نتيجة `liveVerified: false` محفوظة في [evidence/connection-report-build.json](evidence/connection-report-build.json).

محاولات أخرى إلى الخدمة من بيئة البحث أعادت HTTP 502. لا نستنتج أن سينمانا متوقف عند جميع المستخدمين؛ هذا يثبت فشل الوصول من الشبكة المستخدمة هنا فقط.

لذلك ملف المستودع `manifest.json` تمهيدي ومعلن بأنه غير مكتمل. الملف الحي يخرج من الخدمة فقط بعد نجاح اكتشاف الأقسام الأصلية. لا يوجد رقم كتالوجات حية موثوق في هذا التقرير.

## GitHub Actions

المشروع يحتوي وظيفة اختبارات بروتوكول على كل push/PR، وفحص اتصال منفصل على push أو تشغيل يدوي. فشل فحص الشبكة لا يلغي اختبارات البروتوكول، لكنه يبقى ظاهرًا في job وفي `connection-report.json`. إذا نجح الاتصال يصدر `manifest-live.json` ضمن artifact التشخيص.

لا تعتبر علامة CI العامة دليلًا على تشغيل المزود الحي؛ راجع وظيفة الاتصال نفسها. النتائج النهائية المرتبطة بالالتزام تظهر في صفحة Actions للمستودع.

## فحص هاتفك بعد التشغيل

1. شغل الخدمة على شبكة يصل منها تطبيق سينمانا.
2. افتح configure واضغط الاختبار؛ تحقق من وجود الفروع الدقيقة في manifest الحي و`native/index`.
3. اختر كلمة لها أكثر من صفحة نتائج في سينمانا، ثم قارن أرقام الأعمال في النوعين، لا الأسماء فقط.
4. افتح مسلسلًا متعدد المواسم، وحلقة خاصة؛ اختبر ربطها برقم الحلقة الصحيح.
5. افحص الجودات والترجمة العربية والعربية المحسنة وASS على Nuvio وStremio.
6. عند اختلاف حقول الخدمة الحالية، استخدم capture لأرقام الأعمال المتأثرة. المشروع يحتفظ بعقد المصدر لإصلاح الاختلاف على أساس رد فعلي.

النتيجة النهائية لا يمكن تسميتها «تكاملًا حيًا مثبتًا لكل محتوى سينمانا» قبل هذه الخطوات على شبكة متاحة.
