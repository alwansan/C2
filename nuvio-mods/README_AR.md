By: Ali Tuama

السورس المستهدف: Nuvio 0.5.9-beta، commit `db0c50b503039863909c86405907462bf1752193`.

## الاستخدام

فك الحزمة بجانب مجلد سورس Nuvio، ثم شغّل من Python 3.9 أو أحدث:

```bash
python install.py "/storage/emulated/0/Download/Games/NuvioMobile-0.5.9-beta" --dry-run
python install.py "/storage/emulated/0/Download/Games/NuvioMobile-0.5.9-beta"
```

اختياريًا: `--package com.example.alwancinema` لتغيير applicationId. تبقى namespaces ومكتبات Nuvio الأصلية سليمة.

الأداة تفحص كل الملفات قبل الكتابة، تحفظ نسخًا احتياطية داخل `.alwan-mod-backups`، وتسمح بإعادة تشغيلها دون تكرار الإضافات. عند تغيير إصدار Nuvio الجديد للمواضع المطلوبة، ترفض التعديل وتذكر الملف؛ لا يوجد ضمان توافق تلقائي مع أي تحديث مستقبلي. تغييرات خارج مواضع الحقن تُحفظ، ولا تُستبدل ملفات المستخدم كاملة عند اختلافها عن السورس المرجعي.

## الميزات

- مزود سينمانا داخل عملية التطبيق، باستعمال QuickJS الذي يستخدمه Nuvio أصلًا؛ لا يحتاج Termux أو سيرفر Node خارجي.
- نفس ملفات منطق الإضافة: اكتشاف كل التصنيفات والمجموعات والمجموعات الفرعية، دمج كتالوجات اللغات، بحث يبدأ من 0 ويتابع كل الصفحات، التفاصيل والجودات والترجمات.
- التثبيت تلقائي لكل ملف شخصي، مع بقاء الإضافات الأخرى مستقلة. يمكن تعطيل سينمانا من الإضافات.
- إعدادات سينمانا من زر إعداد الإضافة داخل Nuvio: لغة المعلومات، تمييز الترجمات، الجودة المفضلة ومستوى الرقابة.
- البحث العمودي اختياري في المظهر > التخطيط. إيقافه يعيد واجهة بحث Nuvio الأصلية. فلترة النتائج حسب المزود والتصنيف والسنة وأقل تقييم IMDb.
- زر التنزيل في تفاصيل أعمال سينمانا، اختيار الجودة، وتحديد حلقات متعددة. التنزيل والاستئناف والخلفية والمكتبة تعتمد على نظام Nuvio الحديث، دون WorkManager أو ExoPlayer قديم.
- مسار ملفات الفيديو `AlwanCinema/mkv`؛ يحتفظ الملف بامتداده الحقيقي، ولا يتم تغيير MP4 إلى MKV شكليًا. الترجمات محفوظة بملفات جانبية عبر نظام Nuvio.
- البيانات ونسخة إعدادات Nuvio في `AlwanCinema/work/data`؛ انتقال آمن من `work/date` دون استبدال ملف موجود. مجلد `logs` جاهز للسجلات.
- `nuvio-state.zip` يحفظ SharedPreferences وملفات المستخدم الداخلية (ومنها الملف الشخصي المحلي والإضافات والإعدادات والصور). يُستعاد قبل تهيئة واجهة التطبيق في أول تشغيل بعد التثبيت.

## الصلاحيات وحفظ البيانات

نسخة Android full تطلب الوصول للتخزين المشترك. تُفحص الصلاحية عند كل بدء/استئناف تنزيل، ويُفتح طلب السماح إذا سُحبت. لا يعيد Android نافذة صلاحية مُنحت بالفعل.

للاستعادة: احتفظ بمجلد `AlwanCinema` واسمح بالتخزين بعد إعادة التثبيت. أغلق التطبيق طبيعيًا قبل حذفه ليكتمل أحدث حفظ، وتجنب حذف المجلد ببرامج التنظيف. النسخة الاحتياطية محلية وتحتوي بياناتك؛ لا تنشرها. استعادة جلسات خدمات خارجية التي انتهت صلاحيتها لا تُغني عن تسجيل الدخول عند طلب تلك الخدمات.

الحزمة تستهدف Android full. لم نضف سينمانا APK أو DEX أو موارد Android قديمة. ملفات AAR الموجودة أصلًا في سورس Nuvio المرفق باقية كما هي.

## البناء

```bash
./gradlew :androidApp:assembleFullDebug -Pnuvio.android.distribution=full -Pnuvio.ios.distribution=appstore
```

يتطلب JDK17 وAndroid SDK وإمكانية تنزيل اعتمادات Gradle. APK التجريبي يحمل package `com.nuvio.cinemana`؛ إذا اختلف توقيعه عن نسخة قديمة فلن يقبل Android التحديث فوقها. حافظ على مجلد البيانات قبل إزالة النسخة القديمة.

## ملفات الحزمة

- `install.py`: المُثبت؛ لا يحتاج مكتبات Python إضافية.
- `patches.json`: جميع ملفات التعديل ومواضع الحقن.
- `bundle_addon.py`: إعادة إنشاء مزود JavaScript من مجلد سورس الإضافة.
- `addon-source/`: نسخة الإضافة الكاملة مع صفحة الإعداد ذات الحقوق والأيقونات SVG.
- `test_installer.py` و`test_bundle.mjs`: اختبارات التطوير، تُشغّل بجانب مجلدي السورس الأصلي والمعدل؛ ليست لازمة للمُثبت.

ترخيص Nuvio GPLv3 موجود في السورس الأصلي؛ أُرفق السورس الكامل مع التعديلات. راجع نتائج البناء المرفقة قبل اعتبار النسخة مجربة على جهاز فعلي.

## تحديث الأداء P1

الحفظ يعمل على Dispatchers.IO من عامل واحد، ويجمع التغييرات خلال 1.5 ثانية. فحص ملفات المستخدم كل 30 ثانية لا يعيد كتابة النسخة إذا لم تتغير البيانات؛ ملفات كاش سينمانا قابلة لإعادة الإنشاء ولا تدخل النسخة. بطاقات البحث عناصر LazyColumn مستقلة بمفاتيح ثابتة. يعيد المزود استخدام فهرس كتالوجاته المحفوظ حتى 15 دقيقة، ويتوقف عن متابعة صفحات الطلبات الملغاة. لا يُحذف محتوى البحث أو يُحدد عدد نتائجه لتسريع التطبيق.

ملف الأداء للهاتف مبني Release مصغّر لمعمارية arm64-v8a، وموقّع بمفتاح اختبار Android؛ ليس مفتاح نشر خاصًا. أمر بناء نسخة اختبار محسّنة:

```bash
./gradlew :androidApp:assembleFullRelease -Pnuvio.android.distribution=full -Pnuvio.ios.distribution=appstore -Palwan.testSigning=true
```

للنشر الرسمي استخدم إعدادات توقيع release الأصلية ومفتاحك الخاص، دون alwan.testSigning.
