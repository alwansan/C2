# AlwanCinema P8 — إصلاح التفاف عناوين الواجهات

**الأساس:** P7 المبني على Nuvio 0.5.9-beta. هذا إصلاح UI فقط، بدون تعديل بيانات الحساب أو الكاش أو المزود.

## السبب

في `NuvioScreenHeader` كان العنوان يشارك أزرار الصفحة داخل `Row` من دون وزن يضمن حصته من العرض؛ عند زيادة `fontScale` أصبح عرضه شديد الضيق فالتف حرف أو حرفان في سطر مستقل. وعناوين بعض الأعمال والمشغل كانت تُقاس حسب عرض المحتوى من دون تقييد العرض الكامل المتاح.

## الإصلاح

- إضافة `Modifier.weight(1f)` لمجموعة العنوان في الترويسة، مع تخصيص العرض المتبقي بعد الأزرار.
- استعمال `fillMaxWidth()` للعناوين داخل المجموعات ومناطق التفاصيل.
- ضبط `TextAutoSize.StepBased` للعناوين فقط. يحتفظ بأكبر حجم ممكن من إعداد P7، ويصغر عند الحاجة كي لا يظهر حرف منفرد.
- الكلمة الواحدة تعرض بسطر واحد، والعنوان المتكون من عدة كلمات يمكن عرضه على سطرين؛ عند تعذر العرض حتى عند الحد الأدنى يستخدم حذفا بنقاط بدل تحطيم التخطيط.
- شمل عناوين الصفحات المشتركة (البحث، الإعدادات، المكتبة، التنزيلات)، عناوين تفاصيل الأعمال، واختيار الجودة/التشغيل وعناوين صفحات الإعدادات للأجهزة اللوحية.
- لا يغيّر إعدادات المستخدم ولا أحجام خطوط النص العادي ولا الصور أو أنظمة التشغيل.

## التثبيت على السورس

```bash
python apply_p8.py /path/to/AlwanCinema-P7-source
python test_p8.py /path/to/AlwanCinema-P8-source
```

المطلوب بعد بناء APK: اختبار أسماء الصفحات العربية الطويلة، عنوان بحرف عربي طويل، عنوان إنجليزي طويل، والقياسات 80% و100% و140% ووضع RTL، والاختيار داخل المشغل؛ ينبغي ألا يضيع زر العودة أو يخرج المحتوى خارج عرض الشاشة.
