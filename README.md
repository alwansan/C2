# إضافة سينمانا المستقلة — Cinemana Addon

مزود HTTP لـ **Nuvio الأصلي وStremio**. يقرأ واجهات المحتوى التي يستعملها سينمانا، ويقدم `manifest / catalog / meta / stream / subtitles` دون دمج APK أو مكتبات Android. المشروع مستقل وغير رسمي.

**الحالة الحالية:** اكتمل تنفيذ موارد الإضافة واختبارها محليًا. بيانات الاختبار مصطنعة، وليست عينة من فهرس سينمانا. الاتصال الحي من بيئة البناء لم ينجح؛ لذلك لا نعلن أن كل أقسام المزود الحالي أو التشغيل الحي قد تم التحقق منها. الخدمة تكتشف الأقسام الفعلية عند تشغيلها على شبكة يصل منها سينمانا.

## ما يقدمه المشروع

- اكتشاف التصنيفات الأصلية، لغات كل تصنيف، مجموعات الرئيسية، التجميعات وفروعها. لا توجد قائمة أسماء مختصرة ثابتة تُخفي الأقسام الأخرى.
- كتالوجان للبحث الشامل: أفلام ومسلسلات. البحث يبدأ من **صفحة المصدر 0** ويجمع النتائج حتى الصفحة الفارغة، دون قطعها عند 100 نتيجة.
- تصفح الصفحات: كل طلب يعرض 100 نتيجة من النوع المطلوب. الصفحة القصيرة أو المختلطة أو الفارغة بعد الفلترة لا تعني انتهاء المصدر.
- تفاصيل العمل وطاقمه وتصنيفاته وتقييماته وصوره، مع الاحتفاظ بالحقول الأصلية في امتداد `cinemana`.
- حلقات برقم سينمانا الأصلي، ومواسم وحلقات خاصة، مع التحقق من أصل المسلسل قبل تشغيل الحلقة.
- جميع الجودات التي يعيدها `transcoddedFiles`، دون استبدال الروابط أو إخفاء الجودات الأقل. اختيار الجودة يغير الترتيب فقط.
- جميع عناصر `translations` بأسمائها وصيغها الأصلية، بما فيها العربية المحسنة وASS/SSA. إعداد عرض مناسب لـ Nuvio وإعداد ISO لـ Stremio.
- شعار سينمانا الأصلي وصفحة إعداد عربية داكنة بأزرار مستديرة.

## تشغيل سريع على الهاتف

داخل Termux، على شبكة يعمل عليها سينمانا:

```sh
pkg install git nodejs-lts
git clone https://github.com/alwansan/C2.git
cd C2
bash tools/start-termux.sh
```

افتح **http://127.0.0.1:7000/configure** في متصفح الهاتف، اضغط **اختبار الاتصال والكتالوجات**، ثم انسخ رابط التثبيت الذي تولده الصفحة إلى Nuvio أو افتحه في Stremio. يجب استمرار خدمة Termux أثناء استخدام الإضافة. لبعض إصدارات العملاء قيود على HTTP المحلي؛ استخدم خدمة HTTPS على شبكة تصل إلى المزود عند الحاجة.

على الكمبيوتر، Node.js 24 موصى به، والحد الأدنى 22.9:

```sh
npm test
npm start
```

لا توجد حزم npm خارجية للتثبيت.

## ملف manifest.json

[manifest.json](manifest.json) الموجود بالمستودع **قالب تمهيدي فقط**، ويصرح بـ `discoveryComplete: false`. لا يتضمن أسماء أقسام حية لم نستطع جلبها، ولا يُثبت من رابط GitHub الخام باعتباره مزودًا كاملًا.

**الرابط الصحيح للتثبيت يأتي من الخدمة العاملة:** `http://127.0.0.1:7000/manifest.json` على الهاتف نفسه، أو رابط HTTPS لخدمتك. هذا الملف يتولد بعد اكتشاف جميع قوائم الأقسام التي يعيدها المزود. ملف JSON منفرد أو GitHub Pages لا ينفذ طلبات البحث والتفاصيل والمصادر.

للتصدير بعد نجاح الاتصال:

```sh
npm run manifest -- --output=manifest-live.json
```

الملف المصدر لا يغني عن استمرار الخدمة التي توفر بقية المسارات.

## حدود البروتوكول

الإضافة تقدم المحتوى والمصادر والترجمات؛ المشغل والتنزيل والإعدادات المحلية وإدارة مشاهدة المستخدم تتبع العميل. **مشغل سينمانا الأصلي ودمج FFmpeg وتنزيل MKV وحساب سينمانا وتعليقاته واشتراكاته ليست ميزات ينقلها manifest إلى Nuvio أو Stremio.** حقول التخطي والتفاصيل الإضافية محفوظة للمستقبل، لكن العملاء القياسيين قد يتجاهلونها.

لا تتجاوز الإضافة قيود شبكة المزود أو صلاحيات الحساب. قد تتغير واجهات سينمانا؛ لذلك يوجد جرد قابل للمراجعة واختبارات ومخرجات تشخيص بدل ادعاء تكامل حي غير مُثبت.
